# SCADA Platform - 开源工业组态平台

基于 Vue 3 + TypeScript + Konva.js 的工业组态可视化编辑平台。

> 📘 **使用说明书**：[docs/USER_GUIDE.md](docs/USER_GUIDE.md) —— 安装启动、界面操作、状态规则配置、数据源接入与常见问题，面向所有使用者。
> 🚀 **部署指南**：[docs/DEPLOY.md](docs/DEPLOY.md) —— 生产部署（同机同域 / 前后端分开）、Nginx、环境变量与安全加固清单。
> 🤖 **AGENTS.md** —— AI 编码代理工作指南（项目约定、扩展点与常见坑），亦可供新成员快速上手。

## 功能特性

### 可视化编辑
- 拖拽式组件放置
- 框选/Shift 多选，支持批量移动、删除、复制粘贴
- 画布缩放/平移（空白处拖拽平移，滚轮以指针为中心缩放）
- 组件选中/变换
- 吸附对齐（网格吸附 + 拖拽对齐参考线）
- 标尺与小地图
- 撤销/重做操作
- 画布尺寸自定义
- 亮色/暗色主题切换

### 工业组件库

| 分组 | 组件 | 说明 |
|------|------|------|
| 基础组件 | 阀门、泵、储罐、设定值、数值显示 | 通用工业设备；设定值用于运行期向绑定变量下发数值，数值显示以大字展示绑定变量的格式化值（可配小数位与单位） |
| 管道组件 | 管道 | 管道连接件 |
| 电气组件 | 电机、传感器 | 电气设备 |
| 煤矿组件 | 采煤机、掘进机、皮带输送机、通风机、瓦斯传感器、提升机、原煤仓 | 煤矿行业设备 |
| 电厂组件 | 汽轮机、发电机、锅炉、变压器、断路器 | 火电厂热工与电气设备 |
| 化工组件 | 反应釜、换热器 | 化工行业设备 |
| 水处理组件 | 沉淀池、潜污泵 | 水处理行业设备 |

### 实时状态监控
- 自定义状态规则（区间判断、逻辑运算）
- 组件颜色/动画响应
- 数据绑定

### 管道连线
- 端口拖拽连线，自动吸附目标最近端口
- 直线/折线/曲线三种路径算法
- 流动动画效果
- 元素移动后连线自动跟随

### 多数据源支持
- WebSocket 实时推送（支持断线自动重连）✅
- HTTP 定时轮询（失败自愈，自动重试）✅
- OPC UA（经 WebSocket 网关接入，NodeId 映射）✅
- 模拟数据（开发调试，22 台内置设备）✅

### 图层管理
- 背景层/管道层/设备层/标注层
- 可见性/锁定控制
- 图层排序

## 快速开始

### 环境要求

- Node.js >= 18
- pnpm >= 8

### 安装

```bash
pnpm install
```

> pnpm v10+ 默认拦截依赖的构建脚本，本项目已在 `pnpm-workspace.yaml` 中声明允许 esbuild、@parcel/watcher、vue-demi 执行构建，直接安装即可。若曾中断安装导致依赖损坏（报 `Cannot find module .../vite/...`），删除 `node_modules` 后重装。

### 开发

```bash
pnpm dev
```

### 构建

```bash
pnpm build
```

### 测试

```bash
# 运行测试
pnpm test

# 带UI的测试
pnpm test:ui

# 覆盖率报告
pnpm test:coverage

# 监听模式
pnpm test:watch
```

## 组件开发指南

### 注册新组件

```typescript
import { registerComponent } from '@/industrial/registry'
import type { ComponentDefinition } from '@/types/scada'

const MyComponent: ComponentDefinition = {
  type: 'my-component',
  name: '我的组件',
  group: 'basic',
  icon: '<svg>...</svg>',
  defaultWidth: 80,
  defaultHeight: 80,
  defaultConfig: {},
  statusRules: [],
  dataBindings: [],
  properties: [],
}

registerComponent(MyComponent)
```

### 状态规则配置

支持以下条件类型：

- `compare`: 比较运算（>, <, =, >=, <=, !=）
- `range`: 区间判断
- `and`: 逻辑与
- `or`: 逻辑或
- `expression`: 表达式求值

示例：

```typescript
const statusRules = [
  {
    id: 'running',
    name: '运行',
    color: '#00d4aa',
    condition: {
      type: 'compare',
      variable: 'speed',
      operator: '>',
      value: 0,
    },
    priority: 1,
  },
  {
    id: 'high-temp',
    name: '高温',
    color: '#ff4757',
    condition: {
      type: 'and',
      conditions: [
        { type: 'compare', variable: 'temp', operator: '>', value: 80 },
        { type: 'compare', variable: 'speed', operator: '>', value: 0 },
      ],
    },
    priority: 2,
  },
]
```
