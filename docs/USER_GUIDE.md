# SCADA Platform 使用说明书

> 面向使用者的完整操作手册：安装启动、界面介绍、编辑器操作、状态规则配置、数据源接入、项目管理与常见问题。
> 架构设计与二次开发请看项目根目录的 [README.md](../README.md)。生产部署见 [DEPLOY.md](./DEPLOY.md)。

---

## 1. 项目简介

SCADA Platform 是一个基于 **Vue 3 + TypeScript + Konva.js** 的开源工业组态可视化编辑平台。无需后端，打开浏览器即可：

- 从组件库拖入工业组件搭建工艺流程画面：**7 个分组、19 种组件**，覆盖通用设备与煤矿、电厂、化工、水处理行业
- 通过端口拖拽建立组件连线
- 配置状态规则，让组件颜色随实时数据自动变化（运行/停止/高温/瓦斯报警等）
- 接入 WebSocket 实时数据源或使用内置模拟数据调试
- 保存/导出/导入项目，一键进入只读预览模式

## 2. 环境要求与启动

| 要求 | 版本 |
|------|------|
| Node.js | ≥ 18 |
| pnpm | ≥ 8（推荐 10/11，构建脚本白名单已内置） |

```bash
# 安装依赖
pnpm install

# 启动开发服务器，浏览器访问 http://localhost:5173
pnpm dev

# 生产构建（含 TypeScript 类型检查）
pnpm build

# 运行测试
```

> **提示**：pnpm v10+ 默认拦截依赖的构建脚本。本项目已在 `pnpm-workspace.yaml` 中声明允许 esbuild、@parcel/watcher、vue-demi 执行构建，直接 `pnpm install` 即可，无需手动确认。
>
> **生产部署**（Nginx、存储后端、前后端分开部署、鉴权与备份）见 [DEPLOY.md](./DEPLOY.md)。

## 3. 界面总览

### 首页（Dashboard）

三个入口卡片 + 最近项目列表：

- **新建项目**：清空当前状态，进入空白编辑器
- **打开项目**：弹出对话框，选择之前保存到浏览器的项目
- **导入项目**：从本地 JSON 文件导入
- **最近项目**：显示保存在浏览器中的项目及最后修改时间，可直接打开或删除

### 编辑器

| 区域 | 位置 | 作用 |
|------|------|------|
| 工具栏 | 顶部 | 左上角 Logo 点击返回主页；选择/连线/平移工具切换、标尺/小地图开关、撤销重做删除、缩放、画布配置、数据源配置、主题切换、保存/导出/导入、预览 |
| 组件库 | 左侧 | 基础/管道/电气/煤矿/电厂/化工/水处理 7 个分组 22 种内置组件；底部"自定义组件"分组可**手动创建**自己的组件（选形状、定尺寸颜色），持久化到浏览器，与内置组件同等使用 |
| 画布 | 中间 | 1920x1080 画布，支持网格显示、组件拖放、连线绘制 |
| 属性面板 | 右侧 | 选中组件后编辑名称、位置、尺寸、旋转、组件属性、数据绑定、状态规则 |
| 图层管理 | 底部 | 每个图层可切换可见性（眼睛）与锁定（锁头），可新增图层 |

### 预览模式

只读画布 + 实时数据驱动：组件按状态规则变色、显示实时数值、连线（含流动动画）照常渲染。点击"返回编辑器"回到编辑状态。

## 4. 五分钟上手

1. **拖入组件**：从左侧组件库拖动"电机"到画布。组件会**自动绑定同类型模拟设备**（电机 → motor_1），即刻就能看到实时数值与状态变色。
2. **建立连线**：按 `L`（或点击工具栏连线图标）切换到连线工具，组件四边出现端口圆点；从一个端口按住拖到目标组件上松开，**自动吸附目标最近的端口**完成连接。
3. **配置状态规则**：切回选择工具（`V`），点击选中组件 → 右侧属性面板 →"配置状态规则"，添加规则如"speed > 0 → 绿色（运行）"。
4. **保存**：`Ctrl+S` 保存项目到浏览器。
5. **预览**：点击工具栏"预览"，查看实时数据驱动的完整效果。

## 5. 编辑器操作详解

### 5.1 工具切换

- `V` 或工具栏图标：选择工具（选中、拖动、变换）
- `L` 或工具栏图标：连线工具（显示端口、拖拽连线）

### 5.2 组件操作

| 操作 | 方式 |
|------|------|
| 选中 | 单击组件（属性面板同步显示其属性） |
| 框选 | 选择工具下，在画布空白处拖出矩形，框内组件全部选中 |
| 多选 | `Shift`+点击依次加选/减选；选中后可整体拖动、删除、复制粘贴 |
| 移动 | 按住拖动；松开后相连连线自动重新计算路径；多选时整体移动 |
| 对齐吸附 | 拖动中自动与其他组件的边/中线对齐并显示粉色参考线；网格吸附可在"画布配置"中开关 |
| 缩放/旋转 | 选中后拖动四角/四边变换手柄，顶部圆形手柄旋转 |
| 复制/粘贴 | 三种方式：`Ctrl+C` / `Ctrl+V`；工具栏复制/粘贴按钮；支持多选批量复制（副本向右下偏移 20px） |
| 删除 | 三种方式：选中后按 `Delete`/`Backspace`；点击工具栏垃圾桶按钮；点击属性面板底部"删除组件"按钮（均连同相关连线一起删除） |
| 撤销/重做 | `Ctrl+Z` / `Ctrl+Y`（拖入、拖动、连线、属性修改均可撤销） |

### 5.3 画布操作

- 滚轮缩放（以鼠标指针为中心，工具栏或画布右下角显示当前比例）
- **平移**：在画布空白处按住拖动即可移动视图
- **标尺**：工具栏网格图标开关，顶部/左侧显示画布坐标刻度
- **小地图**：工具栏定位图标开关，右下角显示全画布缩略图与当前视口框，点击/拖动可快速导航
- 工具栏"适应画布"重置为 100% 并回到原点
- 画布配置对话框（齿轮图标）：画布尺寸、网格开关与颜色、网格吸附、缩放范围等
- 右上角日/月按钮切换亮色/暗色主题，偏好自动保存

### 5.4 图层管理

- 底部面板可切换每个图层的**可见性**（画布元素随之隐藏/显示）与**锁定**（锁定后元素不可拖动）
- 点击"+"新增图层；组件归属于拖入时的当前活动图层

### 5.5 多画面导航

- 画布上方**页签条**管理画面：`+` 新建，双击页签重命名，页签右侧箭头可复制/删除（至少保留一张）
- 选中任意组件 → 属性面板 → **画面导航** → 选择「点击跳转」的目标画面；预览运行时点击该组件即切换画面
- 预览顶栏若有多张画面，会显示下拉框可手动切换；`/preview?project=工程名&page=画面ID` 可指定起始画面
- 每张画面有自己的元素、连线与图层；**数据源与报警定义是工程级共享**的，切画面不断线、不丢报警
- 切换画面会清空当前撤销栈（避免把上一页的操作撤销到另一页）

### 5.6 设备模板

- 选中画布上的设备（可先配好属性、数据绑定、状态规则）→ **右键 → 存为模板**，命名后进入模板库
- 组件库切到 **自定义组件** Tab，拖「模板卡片」到画布即可实例化：尺寸、属性、绑定、规则一次带出，设备 ID 自动建议
- 模板卡片悬停可删除（已放置的实例会保留）；模板存在存储里，换工程仍可复用

### 5.7 报警外发通知

- 工具栏「通知通道」（纸飞机图标）配置：**Webhook / 企业微信 / 钉钉 / 邮件 SMTP / 短信网关**
- 每条通道可选级别（报警/预警）、触发时机（触发/恢复）、启用开关，并支持「测试」发送
- 同一通道默认 **60 秒内不重复发送**（可在对话框里改），避免告警风暴
- 通道地址与密钥保存在**服务端**，需要工程师及以上账号才能配置；报警发生时由服务端真正外发

## 6. 状态规则配置

选中组件 → 属性面板 → **配置状态规则**：

- **规则列表**：可添加/删除多条规则，点击切换编辑
- **优先级**：数字越小优先级越高，多条规则同时满足时取优先级最高的
- **状态颜色**：命中规则后组件显示对应颜色

支持 5 种条件类型：

| 类型 | 说明 | 示例 |
|------|------|------|
| 比较 | 变量与固定值比较（> < = >= <= !=） | `speed > 0` |
| 区间 | 变量落在 [min, max] 内 | `20 ≤ level ≤ 80` |
| 逻辑与 | 所有子条件都满足 | 温度>80 且 转速>0 |
| 逻辑或 | 任一子条件满足 | — |
| 表达式 | 文本表达式求值 | `speed > 100 AND temp < 80` |

> **注意**：表达式中的逻辑运算符目前只识别**大写** `AND` / `OR`。

各组件默认自带典型规则（电机：运行/停止/高温；储罐：高液位/正常/低液位；阀门：开启/关闭），可直接修改。

## 7. 数据源配置

工具栏"数据源配置"（数据线图标）打开对话框。

### 7.1 模拟数据（默认）

内置 19 台模拟设备，每秒随机刷新，覆盖全部组件分组，用于开发调试：

| 分组 | 设备（变量） |
|------|------|
| 基础/管道/电气 | motor_1（speed, temp, vibration）、pump_1（speed, flow, pressure）、valve_1（openDegree）、tank_1（level, temp）、pipe_1（flowRate）、sensor_1（value） |
| 煤矿 | shearer_1（speed, load）、roadheader_1（cutting, load）、conveyor_1（speed, load）、fan_1（speed, vibration）、gas_sensor_1（density, %CH4）、hoist_1（speed, load）、coal_bunker_1（level, temp） |
| 电厂 | turbine_1（speed, temp）、generator_1（power, voltage）、boiler_1（pressure, level, temp）、transformer_1（temp, load）、breaker_1（closed） |
| 化工 | reactor_1（temp, pressure, level）、heat_exchanger_1（flow, tempIn, tempOut） |
| 水处理 | sediment_tank_1（level, turbidity）、sub_pump_1（running, flow） |

可调整更新间隔（500–10000ms）。

### 7.2 WebSocket 实时推送

- 填写服务地址（如 `ws://localhost:8080/realtime`）
- 可开启**自动重连**并设置重连间隔（1000–30000ms）；意外断线后自动恢复，手动断开不重连
- **消息协议**（服务端推送 JSON，支持两种格式）：

```json
// 格式一：设备映射
{ "motor_1": { "speed": 1500, "temp": 65 } }

// 格式二：单设备对象
{ "deviceId": "motor_1", "data": { "speed": 1500 } }
```

### 7.3 HTTP 轮询

按配置间隔（1000–60000ms）定时 GET 请求地址，响应支持与 WebSocket 相同的三种 JSON 格式（设备映射 / 单设备对象 / 读数数组）。单次请求失败只标记连接错误并继续轮询，恢复后自动回到已连接状态。

### 7.4 OPC UA（网关接入）

浏览器无法直连 OPC UA 二进制协议，通过「OPC UA WebSocket 网关」接入（网关作为 OPC UA 客户端订阅服务器节点并转发 JSON）：

- 配置**网关地址** + **订阅节点列表**（每行一个 NodeId，如 `ns=2;s=motor_1.speed`）
- NodeId 按"设备.变量"映射：`ns=2;s=motor_1.speed` → 设备 `motor_1` 的 `speed` 变量
- 握手协议：连接建立后发送 `{"action":"subscribe","nodes":[...],"samplingInterval":1000}`
- 支持三种推送格式：单点 `{nodeId, value}`、批量 `{changes:[...]}`、聚合映射
- 支持断线自动重连

### 7.5 数据绑定

属性面板"数据绑定"区：

- **数据源设备**下拉：把组件绑定到任意设备（默认按组件类型自动匹配）
- 下方实时显示各绑定变量的当前值；画布组件上同步显示第一个绑定变量的数值

### 7.6 实时数据视图

数据源配置对话框底部展示**所有设备的实时数据**（设备名、变量名、当前值），随数据源刷新自动更新——用于快速确认数据源是否正常出数，以及挑选要绑定的变量。

### 7.6 自定义组件

面板底部"自定义组件"分组的"+"按钮可创建自己的组件：

- 填写名称、选择基础形状（矩形/圆形/三角形/菱形/竖线/横线）、设定宽高与线条颜色，带实时预览
- 创建后出现在分组卡片中，可拖入画布、绑定设备、配置状态规则，与内置组件同等使用
- 自定义组件持久化在浏览器中（独立于项目数据），清除浏览器数据会丢失

## 8. 项目管理

- **保存**（`Ctrl+S`）：保存到浏览器 localStorage，同名覆盖
- **导出 JSON**：下载 `.json` 文件，可归档或分享
- **导入 JSON**：选择导出的项目文件恢复
- **打开项目**：首页"打开项目"卡片或最近项目列表
- **重命名**：编辑器中点击左上角项目名称（铅笔图标悬停时才显示）；首页"最近项目"列表双击项目名称即可就地重命名。已保存过的项目会同步迁移存储记录
- **返回主页**：编辑器左上角 Logo 可点击返回；有未保存更改时会先询问是否保存
- 项目数据保存在浏览器中，**清除浏览器数据会丢失项目**，重要项目请导出 JSON 备份

## 10. 常见问题（FAQ）

**Q1：`pnpm dev` 报 `Ignored build scripts` 或依赖损坏？**
本项目已内置 `pnpm-workspace.yaml` 构建白名单。若曾中断安装导致 node_modules 损坏（报 `Cannot find module .../vite/...`），删除 `node_modules` 后重新 `pnpm install` 即可。

**Q2：组件一直是灰色不变色？**
检查三点：① 数据源已连接（数据源对话框中状态为"已连接"）；② 组件已绑定设备（属性面板"数据绑定"区）；③ 状态规则的条件变量名与设备变量一致（如 motor_1 的变量是 `speed` 而不是 `rotationSpeed`）。

**Q3：连线拖不出来？**
必须先用 `L` 切换到连线工具，端口圆点出现后从端口拖出；在连线模式下组件不可拖动，这是为了防止拖拽冲突。松开时如果不在任何组件上，连线会自动取消。

**Q4：导出的项目在别的电脑打不开？**
导入功能读取的是"导出 JSON"生成的文件，且版本号需为 1.0。项目存在浏览器里的（未导出的）不会跨设备同步。

**Q5：git 推送报 `SSL_ERROR_SYSCALL`？**
一般是网络对 github.com 的连接被重置，为代理分流问题，与项目本身无关。可让 git 走本地代理：`git -c http.proxy=http://127.0.0.1:7897 push`（端口按你的代理软件调整）。

## 11. 已知限制与规划中功能

- "逻辑与/逻辑或"条件暂无嵌套子条件的表单编辑界面（表达式方式可用）
- 单选组件的操作模型下，变换手柄针对整个选区
- OPC UA 需经网关接入（浏览器不支持 OPC UA 二进制协议），网关部署方式见 7.4 节
- 标尺/小地图配色当前为固定暗色风格
- 画面导航目前是元素点击跳转，尚无「返回上一画面」堆栈与按钮预设样式
- 设备模板（图形+绑定+规则一键实例化）与多用户登录仍在规划中
