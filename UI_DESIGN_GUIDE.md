# SCADA Platform - UI 设计提示文稿

## 项目概述

工业组态可视化编辑平台，用于创建和监控工业设备流程图。采用暗色主题，专业工业风格。

---

## 工具栏组件

### 布局结构

```
+------------------------------------------------------------------+
| [Logo] 项目名称  [未保存]    工具按钮组    [配置] [保存] [预览]    |
+------------------------------------------------------------------+
```

### 左侧区域
- Logo图标 (32x32)
- 项目名称文本
- "未保存"警告标签 (橙色)

### 中间工具区
1. **模式切换按钮组**
   - 选择工具 (V) - Pointer图标
   - 连线工具 (L) - Connection图标
   - 选中状态: 背景 #00d4aa (绿色)

2. **撤销/重做按钮组**
   - 撤销 (Ctrl+Z) - Back图标
   - 重做 (Ctrl+Y) - Right图标
   - 禁用状态: 灰色

3. **缩放控制按钮组**
   - 放大 - ZoomIn图标
   - 缩小 - ZoomOut图标
   - 适应画布 - FullScreen图标
   - 缩放百分比显示 (如: 100%)

### 右侧区域
1. **配置按钮组**
   - 画布配置 - Setting图标
   - 数据源配置 - DataLine图标

2. **文件操作按钮组**
   - 保存 (Ctrl+S) - FolderChecked图标
   - 导出JSON - Download图标
   - 导入JSON - Upload图标

3. **预览按钮**
   - 绿色背景 (#00b894)
   - VideoPlay图标 + "预览"文字
